# What to record for the notes (NOTES-COUNCIL K6)

Igor said yes on 2026-11-20. One voice memo per note, recorded on your
phone, is enough: a quiet room, the phone about a hand's width from your
mouth, your normal speaking voice. Read the list in order and leave about
two seconds of silence between items. Re-say any item you stumble on and
just keep going; the cut can drop the bad take.

Send the memos however is easiest (Telegram is fine). They get cut into one
short clip per item (about 15–25 KB each), and each word and sentence on the
page gets a small play button. Nothing plays by itself, and nothing changes
on the page until the clips exist.

If you want to pick an accent: the notes write British IPA (/ɔː/), so say it
the way you'd teach it.

## Memo 1: the au note

Words: automate · auction · cause · launch · fault · authenticate

Sentences:
1. We launch on Monday.
2. Let's automate the release.
3. What caused the outage?
4. It's a config fault, not a code fault.
5. Authenticate before you call the API.
6. The old domain went to auction.

(The sentences are still drafts. If you change them, record your version.)

## Memo 2: the stress note

Pairs, noun then verb:
CONflict, conFLICT · OBject, obJECT · PROject, proJECT · PROgress, proGRESS ·
CONtract, conTRACT · CONtrast, conTRAST · EXport, exPORT · IMport, imPORT ·
CONsole, conSOLE (or whatever pair replaces it, Q7)

Things:
1. create an OBject
2. my current PROject
3. any PROgress on the ticket?
4. I signed the CONtract
5. the data EXport failed
6. check the CONsole

Actions:
1. I obJECT to this approach
2. we proJECT a two-week delay (or the line from your original slide)
3. the migration is proGRESSing
4. conTRAST the two options
5. exPORT it to CSV
6. imPORT the module
