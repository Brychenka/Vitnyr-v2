Igor Shatsev / Notes / Pronunciation

Three letters and a key. Три буквы и один ключ.

Many programmers say “апи кей”: two words, two mistakes. The abbreviation is read as a word, and key as [кей], which a native speaker hears as the letter K. API is spelled out, эй-пи-ай, and key is ки.

Многие программисты по привычке говорят «апи кей»: два слова — две ошибки. Аббревиатуру читают как слово, а key — как [кей], и носитель слышит букву K. API читается по буквам, эй-пи-ай, а key — ки.

01The fix

Spell the letters. Say the word.

Буквы — по буквам. Слово — целиком.

A short abbreviation is read letter by letter, with the English names of the letters. key is a word, and it sounds like ки. Not апи, not сео, not кей.

Короткую аббревиатуру читают по буквам, английскими названиями букв. key — это слово, и звучит оно как ки. Не апи, не сео и не кей.

02Why it happens

The letters from maths class.

Буквы с уроков математики.

Russian speakers use Latin letters every day in maths and physics, named the Latin way: а plus бэ. Those names come back in English, so API turns into а-пэ-и, or into one word, апи. key goes wrong another way: it is read like hey. But кей is the English name of the letter K, so that is what a native speaker hears.

Латинские буквы мы каждый день видим на математике и физике, и называем их по-латински: а плюс бэ. Эти названия переходят в английский, и API превращается в а-пэ-и или в одно слово, апи. С key другая история: его читают как hey. Но кей — это английское название буквы K, и носитель слышит именно её.

  • аA/eɪ/ эй
  • еE/iː/ и
  • иI/aɪ/ ай
  • эрR/ɑː/ ар

03Practice

Say it out loud.

Скажите вслух.

Abbreviations go letter by letter, with the stress on the last letter: эй-пи-АЙ. Every key is ки, in hotkey and keynote too.

Аббревиатуры — по буквам, с ударением на последнюю букву: эй-пи-АЙ. Любой key — это ки, и в hotkey, и в keynote.

  1. i.Can you send me the API key?
  2. ii.Our CEO wants a demo on Friday.
  3. iii.I left two comments on your PR.
  4. iv.The MR is ready for review.
  5. v.There’s a hotkey for that.
  6. vi.Who’s giving the keynote?
